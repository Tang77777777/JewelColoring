# Jewel Coloring

使用 Cocos Creator 3.8.8 和 TypeScript 实现的 Jewel Coloring 核心玩法试玩项目，主要还原宝石选取、暂存、归位与填色通关流程，并非完整商业版本。

原版完整游戏：[Jewel Coloring（Google Play）](https://play.google.com/store/apps/details?id=color.number.paint.pixle.art.sort.jigsaw)

## 在线试玩

[点击开始试玩](https://tang77777777.github.io/JewelColoring/)

## 游戏玩法

点击棋盘上相连的同色宝石将其选中，可以先放入下方托盘暂存，也可以点击对应颜色的空位直接归位。托盘会自动将同色宝石排列在一起，之后仍可重新选中并放回棋盘。将所有宝石放入正确位置，完成整幅宝石图案即可通关。

使用 Cocos Creator 3.8.8 打开本项目，进入 `assets/scenes/JewelColoring.scene` 场景，点击预览即可运行。
